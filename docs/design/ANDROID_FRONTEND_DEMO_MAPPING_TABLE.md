# Android Frontend Demo Mapping Table

Status: `ANDROID_FRONTEND_DEMO_MAPPING_TABLE`

Date: 2026-07-03

Purpose: 将 canonical `Reader UI/frontend-demo/` 的 route/component 原型逐行映射到 Android 当前页面/Composable、状态归属、motion ID、数据源和测试证据。`frontend-demo` 是设计/合约原型，不是 Android 可复制的 CSS/DOM 实现。

## Legend

- `Aligned`: 当前 Android 已有实现，且 route/state/motion 语义基本对齐。
- `Partial`: 当前 Android 有实现，但结构、样式、状态或数据源仍缺一部分。
- `Gap`: demo 有目标结构，Android 当前还是默认 Material3、占位或没有组件。
- `Deferred`: 后续切片实现；当前不应该伪装成已完成。
- `Legacy`: 旧实现留在仓库但当前 AppShell 不再路由到它。
